## Histórico do projeto

- **2026-07-27**: décimo sexto gráfico adicionado (dashboard interativo com mapa coroplético + dispersão + barras via `ggiraph`+`patchwork`, categoria `map`), a partir de [r-graph-gallery.com/414](https://r-graph-gallery.com/414-map-multiple-charts-in-ggiraph.html). A página original tem 6 variações crescentes de interatividade (a primeira, com `mtcars`, não envolve mapa); as outras 5 viraram os botões deste gráfico, a pedido do usuário — mesmo padrão do gráfico de linha interativa com ggiraph. Dados fictícios (investimento em P&D x índice de inovação por país, `set.seed(1414)`) sobre geografia real (`spData::world`), no lugar do PIB x felicidade reais (Gapminder) do original. Pacote novo: `spData` (fornece o mapa-múndi como `sf` sem precisar de shapefile externo). Nesse meio-tempo, uma tentativa anterior (bubble map de terremotos fictícios, também da página 19) foi criada e desfeita na mesma sessão — o usuário na verdade queria replicar o conceito de "múltiplas variações de estilo" da página 414, não um segundo gráfico da página 19.
- **2026-07-27**: décimo quinto gráfico adicionado (bubble map interativo do Brasil com `leaflet`, primeira entrada da categoria nova `map`), a partir de [r-graph-gallery.com/19](https://r-graph-gallery.com/19-map-leafletr.html). Dados fictícios (vendas mensais em R$ mil, `set.seed(2026)`) para 20 capitais/grandes cidades brasileiras no lugar do dataset `quakes` (terremotos perto de Fiji) do original; mapa recentralizado no Brasil. Primeira versão trocou basemap pra `CartoDB.Positron` e paleta pra `BuPu`, mas o usuário não gostou do visual "sem graça" perto do original — revisado ainda na mesma sessão pra manter o basemap de satélite (`Esri.WorldImagery`, igual ao original) e usar `OrRd` no lugar de `BuPu` (mesma família "quente" do `YlOrBr` original, sem copiar a paleta idêntica — ver "Decisões fechadas" em [AGENTS.md](../AGENTS.md)). Pacote novo: `leaflet` (CRAN). Mesmo padrão de thumbnail via `webshot2` dos outros htmlwidgets sem equivalente `ggplot2`.
- **2026-07-24**: arc diagram ([graficos/network/arc-diagram-d3](../graficos/network/arc-diagram-d3)) revertido pra versão original (commit `ef392cb`), a pedido do usuário — as duas ampliações feitas em 2026-07-23 (72 nós + pan/zoom, depois reduzido a 50 nós + clique-pra-fixar) ficaram "muito bugadas" na prática. Voltou a ser 14 nós / 3 grupos / 17 conexões, só com hover (destaca arcos conectados + tooltip), legenda pequena dentro do próprio SVG, sem pan/zoom/clique-pra-fixar — igual à versão publicada originalmente, próxima do [data-to-viz.com/graph/arc](https://www.data-to-viz.com/graph/arc.html). `widget_files/data.js` (introduzido na ampliação, pra evitar duplicar dados entre `script.R`/`widget.html`) removido — a versão restaurada volta a ter os dados hardcoded nos dois lugares, como no commit original.
- **2026-07-24**: décimo quarto gráfico adicionado (série temporal interativa com `dygraphs`, categoria `evolution`), a partir de [r-graph-gallery.com/318](https://r-graph-gallery.com/318-custom-dygraphs-time-series-example.html). Dados 100% fictícios (downloads diários de um app, 300 dias, tendência + sazonalidade semanal) no lugar do CSV real de bicicletas do exemplo original. `dygraphs` é puro htmlwidget sem equivalente `ggplot2`, então `output.png` veio de um screenshot do `widget.html` via `webshot2`, mesmo padrão dos gráficos de rede/streamgraph.
- **2026-07-24**: gráfico de linha interativa com `ggiraph` revisado — em vez de fixar um único tratamento de CSS combinando as técnicas mais úteis, o `widget.html` agora tem uma **barra de botões acima do gráfico** que troca ao vivo entre as 4 variações de interação da página original (hover simples, destacar+apagar outras, hover avançado, tooltip+zoom), a pedido do usuário ("adicione todos os gráficos que tinha na página... faça um gráfico só mas adicione uma barra acima com botões pra alterar o estilo do gráfico abaixo"). Implementado com `htmltools::save_html()` combinando 4 widgets `girafe` (mesmo `plot`/dados, só `girafe_options()` diferente) numa `tagList` só, com JS puro pro toggle — ver README do gráfico.
- **2026-07-24**: décimo terceiro gráfico adicionado (linha interativa com CSS via `ggiraph`, categoria `evolution`), a partir de [r-graph-gallery.com/412](https://r-graph-gallery.com/412-customize-css-in-interactive-ggiraph.html). A página tinha 5 variações de código, mas todas em cima do mesmo gráfico (só o CSS de interação — hover, tooltip, seleção, zoom — mudava entre elas); por pedido explícito do usuário ("se os gráficos forem muito parecidos e as interações mudarem sutilmente, pode colocar na mesma página"), viraram um gráfico só combinando as técnicas mais úteis de cada variação, em vez de uma pasta por variação.
- **2026-07-24**: nono a décimo segundo gráficos adicionados de uma vez, categoria `network`, todos a partir da mesma página ([data-to-viz.com/graph/network](https://www.data-to-viz.com/graph/network.html)), que tem vários demos diferentes em vez de um único gráfico — usuário escolheu, via pergunta explícita, agrupar em 4: **rede direcionada+ponderada** (setas + espessura de linha, une os 2 demos "Directed"), **rede densa hairball** (ilustra o "erro comum" citado na página), **comparação de layouts** (Fruchterman-Reingold vs DrL vs aleatório, 3 painéis via `patchwork`) e **tipos básicos de rede** (não-ponderada vs ponderada, 2 painéis, une os 2 demos "Undirected"). Pacotes novos: `patchwork` (combina múltiplos `ggraph` num único `output.png`) e `visNetwork` (widget interativo com setas nativas + arrastar nós, usado nos 2 primeiros). Ver "Lições aprendidas" em [`AGENTS.md`](../AGENTS.md) pro detalhe do `Rscript` precisar rodar com o working directory dentro da própria pasta do gráfico (senão `ggsave()` salva o PNG na raiz do repo).
- **2026-07-23**: gráfico de arc diagram ajustado de novo, a pedido do usuário — reduzido de 72 nós/6 grupos pra 50 nós/5 grupos (tinha ficado poluído visualmente), adicionado clique-pra-fixar destaque num arco (`.pinned`, persiste sem hover até novo clique ou duplo-clique), e legenda/dica movidas pra fora do SVG (overlay HTML) porque ficavam ilegíveis reescalando junto com o `viewBox` largo da rede. Ver "Lições aprendidas" em [`AGENTS.md`](../AGENTS.md).
- **2026-07-23**: gráfico de arc diagram ampliado bem além do inicial, a pedido do usuário — de 14 nós/17 conexões pra 72 nós em 6 grupos / 115 conexões, e adicionado pan (arrastar) + zoom (scroll) + reset (duplo-clique) no widget D3, já que a rede ficou grande demais pra caber inteira na tela. `script.R` agora exporta os dados (`nodes`/`links`/`groupColor`) pra `widget_files/data.js` via `jsonlite`, fonte única entre a versão estática e a interativa — não editar `data.js` a mão, ele é regenerado a cada `Rscript script.R`.
- **2026-07-23**: oitavo gráfico adicionado (arc diagram, categoria `network`). Primeiro gráfico do projeto com `widget.html` escrito à mão em D3.js puro em vez de gerado por um pacote R — não existe pacote R com arc diagram interativo pronto. `output.png` continua vindo do `ggraph` normalmente, mesmos dados fictícios nas duas versões. Ver "Decisões fechadas" em [`AGENTS.md`](../AGENTS.md).
- **2026-07-23**: sexto e sétimo gráficos adicionados (densidade 2D estática + superfície 3D interativa, categoria `distribution`, mesmo dataset fictício de 4 clusters gaussianos pra ficarem comparáveis).
